motor.c Function Reference

Documentation derived from the current motor control implementation.

motor_start()

Power-up and startup sequence that enables PWM, ADC DMA, timer callbacks, and rotor alignment.

motor_commutate(uint8_t stage, float dutycycle)

Executes one of the six BLDC commutation states and applies the requested duty cycle.

Parameters: stage — Commutation stage index 0–5. dutycycle — Phase PWM duty cycle.

align_motor()

Applies a fixed commutation state for rotor alignment during startup.

process_bemf()

Converts raw BEMF ADC readings into physical voltage and detects zero crossings.

motor_shutdown()

Disables all motor phases and places the driver in a safe off state.

peripherals_init()

Initialization stub for board-level peripheral setup used by the project.

HAL_ADC_ConvCpltCallback()

Signals completion of ADC DMA sampling so the main loop can process updated sensor data.

HAL_ADC_ConvHalfCpltCallback()

Reserved half-transfer callback for future mid-buffer ADC processing.

HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)

Handles TIM2 period events for commutation progress and startup timing.

HAL_TIM_OC_DelayElapsedCallback(TIM_HandleTypeDef *htim)

Reserved callback for future back-EMF interrupt or delay-based processing.

Helper Routines

setgpio(uint16_t pin, GPIO_TypeDef *port)

Set the selected GPIO pin high.

cleargpio(uint16_t pin, GPIO_TypeDef *port)

Set the selected GPIO pin low.

adc_init(ADC_HandleTypeDef *hadc)

Start ADC sampling with DMA into the local buffer.

adc_uninit(ADC_HandleTypeDef *hadc)

Stop ADC DMA sampling.

adc_read(uint8_t channel_num)

Read the latest DMA-buffered ADC sample for a configured channel.

tim_init(TIM_HandleTypeDef *htim, uint32_t Channel)

Start PWM output on the specified timer channel.

tim_uninit(TIM_HandleTypeDef *htim, uint32_t Channel)

Stop PWM output on the specified timer channel.

tim_write(TIM_HandleTypeDef *htim, uint32_t Channel, uint32_t value)

Write a compare value to the selected timer channel.

tim_read(TIM_HandleTypeDef *htim, uint32_t Channel, uint32_t *value)

Read the current compare register value for the timer channel.

pwm_write(uint8_t phase, float dutycycle)

Apply a normalized duty cycle to the specified motor phase.

enable_pwm_phase(uint8_t phase, float dutycycle)

Enable the selected motor phase and apply PWM duty.

disable_pwm_phase(uint8_t phase)

Disable the selected motor phase and set PWM to zero.
