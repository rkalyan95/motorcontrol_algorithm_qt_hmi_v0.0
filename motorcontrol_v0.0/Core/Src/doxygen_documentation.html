Bldc.cpp

File brief: BLDC motor control implementation. Contains BLDC motor control helper functions and commutation routines.

BLDC::BLDC(IMotorDriver *motordriver)

Constructs a BLDC controller instance. Stores the provided H-bridge driver pointer for later control operations.

BLDC::set_motor_speed(float target_rpm)

Sets the target motor speed. Calculates a target torque, current, and PWM duty cycle based on the requested RPM.

Parameter: target_rpm — Target speed in Revolutions Per Minute.

BLDC::get_motor_speed(float *rpm)

Retrieves the current estimated or measured motor speed.

Parameter: rpm — Pointer to store the result in RPM.

BLDC::get_motor_posn(float *ang)

Retrieves the current rotor position.

Parameter: ang — Pointer to store the result in degrees or radians.

BLDC::get_motor_tempe(float *temp)

Retrieves the motor temperature.

Parameter: temp — Pointer to store the result in Celsius.

BLDC::get_phase_emf(uint8_t phase, float *emf)

Retrieves the back-EMF voltage for a specific phase.

Parameters: phase — Phase index. emf — Pointer to store the result in Volts.

BLDC::get_phase_current(uint8_t phase, float *curr)

Retrieves the instantaneous phase current.

Parameters: phase — Phase index. curr — Pointer to store the result in Amperes.

BLDC::start_motor_commutation(uint8_t current_stage, float duty)

Starts commutation for the selected motor stage and applies the requested PWM duty cycle.

Parameters: current_stage — Commutation stage index. duty — PWM duty cycle.

BLDC::shutdown_all()

Disables all motor PWM outputs and places the driver into a safe state.

BLDC::align_motor()

Aligns the rotor by applying a fixed commutation pattern during startup.

BLDC::read_all_sensors()

Reads bus voltage, temperature, back-EMF, and current feedback sensors.

BLDC::start_motor_openloop(float targetrpm)

Performs open-loop startup and ramps commutation timing based on requested speed.

Parameter: targetrpm — Desired motor speed in RPM.

BLDC::run_speed_pid(float target_rpm)

Runs PID-based speed control to track the requested RPM.

Parameter: target_rpm — Desired speed in RPM.
